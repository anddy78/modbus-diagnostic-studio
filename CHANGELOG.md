# Changelog

## 0.1.0-beta

First beta GUI release for Windows.

Included in this beta:

- Master read FC01-FC04.
- Protected master write FC05, FC06, FC15 and FC16.
- Slave Simulator RTU for FC01, FC02, FC03, FC04, FC05, FC06, FC15 and FC16.
- Passive Sniffer Diagnostic.
- Capture export.
- Operation log export.
- Meters tab.
- Portable Windows build.

Notes:

- Sniffer mode remains passive and must never transmit.
- Write operations are active actions and require explicit confirmation.
