# Skill: Software Architect

Use this skill for architecture, planning and repository structure.

Rules:
- Do not implement code unless explicitly asked.
- Prefer small, layered architecture.
- Keep core logic independent from GUI.
- Avoid framework lock-in inside protocol modules.
- Produce diagrams as text when useful.
- Identify risks and tradeoffs.
- Separate confirmed requirements from assumptions.
- Use Windows/PowerShell commands only when giving commands to the user.

Deliverables should include:
- proposed module boundaries
- data flow
- dependency direction
- test strategy
- packaging implications
- risks and open questions

For this project:
- This is a new independent repository.
- The reference repo is only a technical reference.
- The final app must be self-contained for Windows.
- Prefer PySide6 native desktop GUI.
- Local web GUI is secondary and requires explicit approval.
